# Vefogix Marketplace Suite

> High-authority publisher marketplace and SEO guest post discovery platform. Features domain metrics (DA, DR, Semrush/Ahrefs traffic), price tracking, and direct ordering simulator. Crafted by [tarikislam.in](https://tarikislam.in).

---

## 🚀 Quickstart

Run with pure Python standard library (no dependencies required):

```bash
python server.py
```
Or double-click `run.bat`. Then open [http://localhost:8080](http://localhost:8080) in your browser.
